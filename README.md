# XIV Port Studio

XIV Port Studio is a Dalamud plugin for porting outfits from other games into FFXIV. Pick an item, then define the materials and textures it should use so the result can be exported as a Penumbra mod.

> [!NOTE]
> XIV Port Studio is in early development and is currently available as a **testing-only** plugin.

## Usage

- `/xps` opens the main window.
- `/xpsconfig` opens the configuration.
- `/xpsimport` opens the Sims 4 package importer.

## Installation

1. In game, open `/xlsettings` and go to **Experimental → Custom Plugin Repositories**.
2. Add this URL and save:

   ```text
   https://raw.githubusercontent.com/link-0402/DalamudPlugins/main/repo.json
   ```

3. In the same settings, enable **Get plugin testing builds**. XIV Port Studio only appears when testing builds are enabled.
4. Open `/xlplugins`, search for **XIV Port Studio**, and install it.

[Penumbra](https://github.com/xivdev/Penumbra) is required to use the exported mods.
